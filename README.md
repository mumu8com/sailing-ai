# Sailing AI v1
مساعد ذكي متخصص في قوانين سباقات الشراع.

## التشغيل
npm install
cp .env.example .env.local
npm run dev

بدون مفتاح AI يعمل التطبيق بوضع محلي بسيط. لإجابات النموذج الحية أضف AI_GATEWAY_API_KEY.

الموديل الافتراضي الحالي: openai/gpt-6.1-sol.

## التطوير التالي
Supabase + RAG + Case Book + رفع صور ومخططات + حسابات المستخدمين + سجل المحادثات + وضع تدريب.

واجهة الحساب تتضمن حالة الاشتراك وزر الترقية للحساب المدفوع.
